# CAT Quant PYQ — topic-wise question papers

Live site: **https://jayamishra2520-a11y.github.io/quant-pyq**

Topic-wise CAT Quantitative Ability past-year questions with answer keys, covering
**every CAT slot from 2017 to 2025 — 612 questions across 18 topics, from all 24 papers.**

## Where this comes from

**398 questions** come from official IIM CAT **candidate response sheets** — the static
page IIM publishes showing one candidate's exam with the correct answers marked. Nothing
in them was authored, transcribed or reconstructed.

**214 questions** come from slots IIM never published a response sheet for: CAT 2017 and
2018 predate the format entirely (the earliest test code in that namespace is `CAT191`),
and three later sheets — 2019 slot 2, 2021 slot 3, 2025 slot 3 — were never indexed
publicly. Those are taken from Cracku's published copy and are labelled **via cracku** on
every page they appear on, because they are that site's transcription and that site's
answer rather than an official key.

## Two things worth knowing

- **Math-typeset questions from official sheets are images.** The response sheet publishes
  them that way, so they are embedded exactly as published — no transcription step, so no
  transcription error is possible.
- **CAT randomises question and option order per candidate.** A sheet's "Q7" is that
  candidate's seventh question, not the paper's, so questions are labelled by year and slot
  only. Option letters are the order shown in these PDFs and the answer key matches them —
  but they will differ from another site's lettering. When cross-checking, compare the
  answer's *value*, not its letter.
