# CAT Quant PYQ

**Live site:** https://jayamishra2520-a11y.github.io/quant-pyq/

A topic-wise CAT Quantitative Ability PYQ practice library covering CAT 2017–2025, with questions and answer keys organised by topic.

## Coverage

- 18 Quant topics
- CAT papers from 2017 to 2025
- Questions and answer-key PDFs
- Topic-wise practice interface

## PDF hosting note

The website interface has been copied into this repository. To keep every question and answer-key link working without changing or compressing the original PDF files, the PDFs are currently served from the original public project at https://r4plh.github.io/quant-pyq/.

If those files are moved or the original site is taken offline, the PDF links here will need to be updated or the PDFs mirrored into this repository.

## Source and accuracy notes

The question bank's original README and source notes distinguish official IIM CAT candidate response-sheet material from questions transcribed from other published sources. Please retain those distinctions when using or sharing the material.
